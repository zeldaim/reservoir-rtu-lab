## 제출물 3가지 (모두 필수)
- [ ] **① 개발 문서 PDF** — `docs/개발문서_초안.md` → PDF
  - [ ] 기획 의도 · 주요 기능 · 구현 과정 · 개선 방향 네 장이 다 있음
  - [ ] 회로 캡처 · 실행 캡처 · 측정 표
  - [ ] 생성형 AI 를 어디에 · 왜 썼는지 분명함
  - [ ] 시뮬레이터로 구현했다고 명시
- [ ] **② 시연 영상 5분 이상 ~ 10분 이내** (길이 꼭 확인)
  - 장면 순서 (장치가 주인공):
    1. 회로 · 부품 소개 (1분)
    2. 정상 출입 → 수위 변화에 따른 자동 밸브 · 펌프 (1~2분)
    3. 무차별 대입 → 잠금 · 경보 (1분)
    4. 인증 없는 침입 → `INTRUSION` (30초)
    5. 수위 급변(센서 조작) → 경보 (30초)
    6. FreeRTOS 분리 전 · 후 `stat` 비교 (1분)
    7. AI 사고 리포트 (1분) · (있으면) ML 탐지 · 자동 대응
    8. 정리 · 개선 방향 (30초)
